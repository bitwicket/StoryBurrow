# Save Manager - Manage and Edit Game Saves


A full Save manager. 
- Saves shows current saves with image and details.
- [Snapshots](/docs/images/save_snapshot.png) shows save snapshots taken when the game is updated.
- Import can upload saves from other devices if you are migrating or using a provided save.
- Variables - Opens the [Save Editor](/docs/images/save_editor.png) allowing simple value (choice toggles, points, money, etc.)
